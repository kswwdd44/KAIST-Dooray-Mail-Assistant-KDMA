KAIST Dooray Mail Assistant for Chrome · 시행일 2026년 8월 12일

KAIST Dooray Mail Assistant for Chrome은 Sunwook Kim이 개발한 비공식 Chrome 확장 프로그램이며 KAIST, Dooray 또는 Google의 공식 제품이 아닙니다.

1. 처리하는 정보

확장 프로그램은 사용자가 기능을 이용하기 위해 제공한 Gemini API 키, 사용자 프로필, 기본 서명, 말투와 글자 크기 설정을 브라우저에 저장합니다. 사용자가 AI 답변 생성이나 요약을 요청하면 선택한 메일의 제목, 보낸 사람, 본문, 선택한 문장 및 사용자가 입력한 질문을 처리합니다.

2. 처리 목적과 전송 시점

메일 정보는 답장 초안, 요약 및 후속 답변을 생성하는 목적으로만 사용됩니다. 최초 동의 전에는 메일 내용을 읽지 않으며, 동의 후에도 사용자가 답장 초안·요약 등의 버튼이나 전송 버튼을 직접 누른 경우에만 해당 정보를 Google Gemini API로 전송합니다. 메일 가져오기와 다시 읽기만으로는 Gemini API를 호출하지 않습니다.

3. 외부 서비스 제공

AI 기능 실행에 필요한 정보는 HTTPS를 통해 Google Gemini API로 전송됩니다. Google의 데이터 처리는 Gemini API 약관과 Google 개인정보처리방침의 적용을 받습니다.

Google의 Gemini API 약관에 따르면 무료 등급의 입력·출력 데이터는 Google 제품 개선에 사용되며 품질 개선을 위해 사람 검토자가 읽고 처리할 수 있습니다. 무료 등급에는 민감하거나 기밀이거나 개인적인 정보를 전송하지 마세요.

4. 개발자의 수집 및 보관

개발자가 운영하는 별도 서버는 없으며 개발자는 사용자의 메일 내용, 질문 또는 API 키를 수집하거나 열람하지 않습니다. API 키와 설정은 chrome.storage.local을 이용해 사용자의 브라우저에만 저장됩니다. AI 대화 내용은 확장 프로그램의 현재 실행 메모리에만 유지되며 별도 서버에 영구 저장되지 않습니다.

5. 이용자의 선택과 삭제

사용자는 설정의 API 키·설정 삭제 버튼으로 저장된 API 키와 모든 설정 및 동의 기록을 삭제할 수 있습니다. 확장 프로그램을 삭제해도 해당 확장 프로그램의 로컬 저장 데이터가 제거됩니다. 동의를 철회하면 다시 동의하기 전까지 메일 인식과 AI 기능을 이용할 수 없습니다.

6. 데이터 이용 제한

확장 프로그램은 사용자 데이터를 광고, 사용자 추적, 판매 또는 신용평가 목적으로 이용하지 않습니다. 개발자는 사용자 데이터를 제3자에게 판매하지 않으며, 확장 프로그램의 단일 목적인 메일 답변 지원을 제공하는 데 필요한 범위를 넘어 사용하지 않습니다.

7. 보안과 이용자 책임

외부 전송은 HTTPS로 암호화됩니다. 각 사용자는 본인의 Gemini API 키를 사용해야 하며 키를 다른 사람과 공유해서는 안 됩니다. 또한 조직의 보안 정책상 외부 AI 서비스로 메일 내용을 전송할 수 있는지 확인할 책임이 있습니다.
